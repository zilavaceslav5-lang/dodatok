# Євроізол — аналіз закупівель

Локальна перша версія застосунку. Дані зберігаються у браузері цього комп’ютера.

## Запуск

1. Відкрийте термінал у цій папці.
2. Виконайте: `node server.js`.
3. Відкрийте `http://localhost:4173`.

## Що працює

- бюджетний і комерційний реєстри;
- додавання закупівель і результатів торгів;
- імпорт каталогу Євроізол з CSV;
- автоматичне зіставлення назви й характеристик;
- позначення «Потрібно перевірити»;
- завантаження останніх записів Prozorro через публічний API;
- Excel-сумісний експорт із двома аркушами.

Email та фоновий запуск о 09:00/18:00 позначені в інтерфейсі, але не активовані: для цього потрібні погоджені дані SMTP/пошти й процес, який працює постійно.
